Titulo: Escolher entre banco de dados instalado localmente ou Container.
Status: Aceito.
Contexto: Precisávamos escolher qual seria o melhor custo pensando no futuro.
Decisão: Escolhemos Container pela padronização do ambiente e o isolamento de dependências.
Consequências: Ganhamos algo rápido e prático com o comando "docker compose up -d" criando todo os serviços, porém com uma curva de aprendizado maior.
Alternativas: Instalação local.
